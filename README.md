# Packet Lantern: Network Traffic Triage Tool

[🌐Live Demo: https://packet-lantern.vercel.app ](https://packet-lantern.vercel.app/) 

A small, browser-based educational tool. You export a Wireshark packet list as CSV, open it here, and get a plain-English triage report showing which traffic patterns deserve a closer look and why.

**Central lesson:** an anomaly is a starting point for investigation, not proof of compromise. Detection tells an analyst where to look. Investigation determines what actually happened.

## Educational Use
Built for cybersecurity students. Only analyse traffic from systems and networks you own or are authorised to monitor. Alerts never claim an attack happened, and the tool uses explainable rules, not machine learning.

## Run it locally (Windows)
1. Keep all files in one folder (`index.html`, `styles.css`, `script.js`, `samples.js`, `samples/`).
2. Double-click `index.html`. It opens in your default browser (Edge, Chrome or Firefox).
3. Click **Load Normal Sample**, **Load Suspicious Sample** or **Load Mixed SOC Lab**, or upload your own CSV.

Nothing needs installing. To host it later, upload the same folder to any static host.

## Export Wireshark packets as CSV
Stop your capture, then choose **File > Export Packet Dissections > As CSV**, keep the default columns, and save. Upload that file here.

## Supported CSV fields
Column names are matched case-insensitively with common variants.

| Field | Accepted names (examples) |
|---|---|
| Source | Source, Source IP, src, ip.src |
| Destination | Destination, Destination IP, dst, ip.dst |
| Protocol | Protocol, proto |
| Length | Length, len, frame.len |
| Info | Info, Information |

Missing columns do not crash the tool. It explains what is missing and which rules cannot run.

## Detection rules and default thresholds
| Rule | Default (greater than) |
|---|---|
| High activity host: packets per source | 50 |
| Possible host scanning: unique destinations per source | 10 |
| Possible port scanning: unique destination ports, one source to one destination (needs ports in Info) | 10 |
| High ICMP activity: ICMP packets per source | 30 |
| High DNS activity: DNS packets per source | 30 |
| Repeated source-to-destination packets | 40 |
| TCP SYN heavy: `[SYN]` packets per source (needs flags in Info) | 20 |

Every alert shows the observed activity, the threshold, why it could matter, possible benign explanations and suggested investigation steps.

**Severity** is investigative priority, not certainty. It scales with how far a count is above its threshold (Informational, Low from 1.25x, Medium from 2x, High from 5x). DNS and repeated-communication alerts are capped at Medium.

**Investigation score:** each alert adds visible points (Informational 5, Low 10, Medium 20, High 30). Labels: none, Mild (under 25), Elevated (under 60), High Activity. It is a reading aid, not a probability.

## Why thresholds are not universal
The defaults are educational. A busy server may legitimately send thousands of packets, while the same activity from a laptop might deserve investigation. Adjust thresholds to your environment.

## Limitations and false positives
- A CSV holds less than a full PCAP; ports and flags are read from Wireshark's Info text.
- Encrypted traffic limits visibility.
- Packet volume alone does not indicate malicious activity; backups, updates and monitoring tools trigger these rules too.
- No timing analysis: bursts and steady traffic look the same.
- NAT can make many devices look like one host.
- Protocol labels depend on Wireshark's interpretation.
- No malware analysis. This does not replace Wireshark, an IDS, a SIEM or professional monitoring.
- Files over 200,000 packets or 50 MB are refused.

## Privacy design
Analysis runs entirely in your browser. The code makes no network requests, and the page's Content-Security-Policy blocks connections to other sites. There are no analytics, cookies, tracking, ads, telemetry or external services. CSV text is untrusted and is only inserted into the page as plain text, never as HTML.

## Sample data
`samples/normal-traffic.csv`, `samples/high-volume-traffic.csv` and `samples/mixed-soc-lab.csv` are fictional and use only private and documentation IP ranges. The demo buttons use the same data (generated by `samples.js`). Demo results are labelled **Demo Data**.

## Suggested demo
1. Normal sample: no alerts.
2. Suspicious sample: High activity host alert.
3. Mixed SOC Lab: scanning, ICMP, repeated communication and SYN alerts.
4. Explain the benign explanations on each alert: detection is the start of an investigation, not the verdict.
